# ¿Cómo modelar usando grafos ponderados?
Código y datos utilizados para generar el material de la presentación disponible en https://www.youtube.com/watch?v=YY_WphTx7RI&t=43s.\
Se muestran diversas herramientas para el análisis de grafos ponderados, destacando cómo el espectro de una matriz asociada a un grafo nos revela información clave acerca de su estructura. Asimismo, se muestran dos ejemplos de aplicación: análisis de participación de personajes en película de Star Wars y red de conectividad carretera de Jalisco.
